## 🌟 أبرز مميزات المنظومة (Core Features)

1. **حوكمة نتائج الامتحانات (Exam Embargo Governance):**
   - حجب نتائج ونماذج إجابات الامتحانات تلقائياً حتى انتهاء تاريخ وساعة نهاية الامتحان رسمياً لمنع تسريب الأسئلة وضمان تكافؤ الفرص.
   - عداد تنازلي رقمي حي بالأيام والساعات والدقائق والثواني حتى موعد فك الحجب التلقائي.

2. **نظام المعاينة المجانية (2 Free Previews):**
   - إتاحة حصتي معاينة مجانية لكل معلم ومادة لأي طالب لتجربة الشرح والأسلوب قبل الاشتراك.

3. **المذكرات والتدريبات التفاعلية (Booklets & Instant Practice):**
   - رفع مذكرات الشرح بصيغة PDF.
   - تدريبات تفاعلية مع تصحيح فوري وشرح تفصيلي للحل فور إجابة الطالب.
   - مذكرات YA7EDU الحصرية للأوائل بإدارة الـ Admin.

4. **نظام كروت شحن السناتر (Vouchers Engine):**
   - توليد كروت شحن بأكواد PIN فريدة ومدد صلاحية متعددة (شهر، 3 أشهر، ترم، سنة).

5. **تجديد اشتراكات المعلمين عبر الواتساب:**
   - بطاقة إحصائية لمتابعة وقت الاشتراك المتبقي للمعلم مع زر تواصل مباشر بالدعم الفني: `01090138676`.

6. **منظومة تسجيل الدخول الموحد والتعرف التلقائي:**
   - كشف تلقائي لنوع الحساب (طالب، معلم، أو إدارة) مع إمكانية إنشاء حساب طالب جديد وتحديد الصف والشعبة والمحافظة.

## 🚀 تشغيل المشروع محلياً (Local Development)

```bash
# تثبيت الحزم
npm install

# تشغيل خادم التطوير
npm run dev
```

افتح المتصفح على: `http://localhost:3000`
